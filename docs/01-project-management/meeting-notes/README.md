# Sitzungsnotizen

Hier liegen öffentliche, bereinigte Ergebnisnotizen und Vorlagen. Unterzeichnete Protokolle, persönliche Kontaktdaten und Originalkorrespondenz gehören in das private Projektarchiv.

- [Kick-off: rekonstruierter Vermerk](kickoff-summary.md)
- [Vorlage für künftige Statusmeetings](status-meeting-template.md)

Eine Vorlage oder Rekonstruktion belegt weder eine tatsächlich erfolgte Sitzung noch eine fristgerechte Zustellung. Keine zusätzlichen Meetings werden rückwirkend erfunden.
