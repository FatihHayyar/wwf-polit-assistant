# Prüfung – 13. Oktober 2026

Dieser lokale Arbeitsstand ergänzt die [Prüfung vom 12. Oktober](review-2026-10-12.md). Ollama-Experimente wurden verworfen; die Anwendung verwendet `rule-based-v7` und eine editierbare JSON-Taxonomie. Es wurde kein LLM-Dienst integriert. Die Änderungen wurden noch nicht gepusht.

| Prüfung | Ergebnis |
|---|---|
| Backend | 91 isolierte Tests erfolgreich; anschliessende gezielte Prüfung der Nummernsuche/Gruppierung ebenfalls erfolgreich |
| Frontend | JavaScript-Syntax sowie Übersetzungs-/Darstellungsprüfungen erfolgreich, inklusive lokaler/globaler Fallback-Anzeige |
| Entwicklungsset | Gleiche 50 reale Quellen: bisherige Regeln 40/50, v7 50/50; WWF 20/20, fachfremd 20/20, Grenzfälle 10/10 |
| Mehrfachthemen | Alle fünf mehrthematischen Beispiele erfüllen die vorab festgelegten Erwartungskriterien |
| Parallele Auswertung | 300 Beispiele ergeben seriell und parallel dieselben Kategorien, Scores und Confidence; PostgreSQL schreibgeschützt |
| Backfill | Alle 2.951.254 Quellen in neun Bereichen mit v7 abgedeckt; unabhängige schreibgeschützte Prüfung meldet je Bereich 0 fehlende und 0 veraltete Zuordnungen |
| Gruppierung | Jura-Geschäfte 340896/340897 ergeben schreibgeschützt eine Karte mit beiden Quellzugängen; verschiedene Tage/Körperschaften und Pagination bleiben getrennt |

Die Backfill-Neuberechnung änderte Klassifikationen und deren Evidenz, keine Quelldaten, und erzeugte keine Benachrichtigungen. Fehlerhaftes HTML einer Quelle führte zu einem Abbruch; nach einer getesteten Fehlerbehandlung wurde der Lauf ohne Verlust abgeschlossener Batches fortgesetzt und vollständig beendet.

Das gezielt zusammengestellte Entwicklungsset enthält 49 Geschäfte und ein Winterthurer Dokument zur kommunalen Wärmeversorgung. Erwartete Kategorien stammen aus den Quellen und nicht aus Modellantworten oder bestehenden Klassifikationszeilen. Die Regeln wurden auf diesem Set entwickelt. Es ist kein ungesehener, repräsentativer WWF-Prüfdatensatz. Technische Abdeckung ist keine Aussage über 100 % fachliche Genauigkeit des Gesamtbestands. Expertenevaluation und WWF-Abnahme bleiben offen.
